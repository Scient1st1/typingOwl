# 🦉 Typing Owl Adventure

Welcome to **Typing Owl Adventure**, a fun, interactive, and beautifully designed web-based typing tutor created specifically for 3rd-grade students! 

This educational application helps children practice their typing skills in a stress-free, engaging, and rewarding environment with the help of a friendly animated Owl teacher.

## ✨ Features

- **Bilingual Support (EN / KA):** Seamlessly switch between English and grammatically curated Georgian texts to practice typing in both languages.
- **Smart Virtual Keyboard:** An on-screen interactive keyboard that lights up exactly which key the student needs to press next, helping them learn proper finger placement without looking down at their physical keyboard.
- **Real-Time Visual Feedback:** Immediate color-coded feedback (vibrant green for correct, soft red for mistakes) with built-in layout stabilization so the text never jumps or shakes disruptively.
- **Animated Owl Companion:** A cute owl character reacts in real-time to the student's progress, shaking its head gently on mistakes and bouncing happily when a sentence is completed!
- **Celebratory Rewards:** Finishing a typing challenge triggers an exciting burst of confetti.
- **Printable Certificates:** A beautifully designed, colorful, kid-friendly "Typing Superstar" certificate can be viewed and natively printed/saved as a PDF right from the browser. It grades out of 100 points to keep the scoring simple and encouraging.
- **Soothing Background Audio:** A relaxing bell loop plays at a low volume in the background, starting automatically the moment the student begins interacting with the game.
- **Accessible Controls:** Features a convenient floating mute button to toggle the background audio anytime.

## 🚀 Technologies Used

- **HTML5 & CSS3:** Completely custom, responsive layout featuring vibrant pastel colors, gradients, and CSS micro-animations tailored for a premium children's aesthetic.
- **Vanilla JavaScript (ES6+):** Lightweight, dependency-free core game logic handling keystrokes, language toggling, and DOM manipulation.
- **Vite:** Next-generation frontend tooling for instantaneous local development.
- **Canvas Confetti:** For high-performance, joyful celebration effects.

## 🛠️ How to Run Locally

1. **Install Dependencies:**
   Make sure you have [Node.js](https://nodejs.org/) installed, then run:
   ```bash
   npm install
   ```

2. **Start the Development Server:**
   ```bash
   npm run dev
   ```

3. **Open the Game:**
   Open your browser and navigate to `http://localhost:5173` (or the local URL provided in your terminal).

## 🎵 Assets
- **Audio:** Ensure that your `Bell Ding Level.mp3` file is placed directly in the `/public` folder for the background audio loop to work properly!
